Installation

Drop in the CDN link inside your <head>. No build step, no JavaScript dependency. Pure CSS.

HTML

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/ibp-max@3.1.24/ag.css">

Conventions

Naming Guide

AG uses a compact, segment-based naming system. Each class name encodes the property namespace, sub-property, and value — separated by hyphens.

Flex Utilities — s-f-*

s- f- jc- c

s = style · f = flex · jc = justify-content · c = center

Segments: jc justify-content · ji justify-items · js justify-self · ac align-content · ai align-items · as align-self · fd flex-direction · fw flex-wrap · fg flex-grow · fs flex-shrink · fb flex-basis

Padding — p-*

p- lr- 16

p = padding · lr = left + right · 16 = 16px

Direction codes: t top · b bottom · l left · r right · tb top+bottom · lr left+right · (none) all sides

Buttons — a-b-*

a- b- 1

a = anchor/action · b = button · 1–5 = variant index

Variants: a-b-1 solid gradient · a-b-2 outlined · a-b-3 ghost · a-b-4 bare · a-b-5 compact · f-b-1 fab/icon

Value Shorthands

c = center  fs = flex-start  fe = flex-end  sb = space-between  sa = space-around  se = space-evenly  w = wrap  nw = nowrap  inh = inherit  u = unset
✦
Responsive suffix -l (e.g., s-d-n-l) applies the rule only at ≤1024px. Breakpoint-aware grid sizing uses the ag-c attribute with fraction notation.

Layout

Grid System

AG uses an attribute-based grid. Rows use [ag-r] and columns use [ag-c] with fractional notation. The grid adapts its column count automatically based on the breakpoint.

ℹ
Column sizes are expressed as fractions like ag-c="1/4". Chain multiple breakpoint values: ag-c="1/4 2/8 3/12" means 1/4 at small, 2/8 at medium, 3/12 at large.
How ag-r and ag-c Work
AttributeRoleCSS Effect
ag-rRow containerdisplay: flex; flex-flow: row wrap; align-items: flex-start;
ag-cColumn childAuto-grows if empty, fixed width if fraction specified
ag-c=""Fluid columnflex-grow: 1; flex-basis: 0; — fills available space
ag-c="N/T"Fixed fractionwidth: calc(100% * N / T - spacing)
ag-r ag-cNested row+colAn element can be both a row and a column simultaneously

Extension Guide

What's Missing — Custom CSS Guide

AG covers the essentials, but several common CSS patterns are intentionally absent or thin. This section documents the gaps so developers can write targeted custom CSS to fill them — without duplicating or fighting the framework.

⚠
Always add custom classes in a separate file loaded after ag.css so your rules win without needing !important. Follow AG's naming prefix convention — e.g. use .ag-x-* for your extensions — to avoid collisions.
1 — Gap / Gutter (Flexbox & Grid)
⚠
Missing entirely. AG has no gap, row-gap, or column-gap utility classes. The grid uses var(--gcs) padding on columns, not gap. You'll need to add your own.
CSS — suggested additions
/* Gap utilities — add to your custom.css */
.ag-x-gap-4  { gap: 4px; }
.ag-x-gap-8  { gap: 8px; }
.ag-x-gap-12 { gap: 12px; }
.ag-x-gap-16 { gap: 16px; }
.ag-x-gap-20 { gap: 20px; }
.ag-x-gap-24 { gap: 24px; }
.ag-x-gap-32 { gap: 32px; }

.ag-x-rg-8   { row-gap: 8px; }
.ag-x-rg-16  { row-gap: 16px; }
.ag-x-cg-8   { column-gap: 8px; }
.ag-x-cg-16  { column-gap: 16px; }
2 — CSS Grid Layout (display: grid)
⚠
Missing entirely. AG uses a flexbox-based grid (ag-r / ag-c). There are no display:grid, grid-template-columns, grid-column, or grid-template-areas utilities.
CSS — suggested additions
/* CSS Grid utilities */
.ag-x-dg  { display: grid; }
.ag-x-dig { display: inline-grid; }

/* Common column templates */
.ag-x-gc-2  { grid-template-columns: repeat(2, 1fr); }
.ag-x-gc-3  { grid-template-columns: repeat(3, 1fr); }
.ag-x-gc-4  { grid-template-columns: repeat(4, 1fr); }
.ag-x-gc-auto { grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); }

/* Span helpers */
.ag-x-cs-2 { grid-column: span 2; }
.ag-x-cs-3 { grid-column: span 3; }
.ag-x-rs-2 { grid-row: span 2; }
